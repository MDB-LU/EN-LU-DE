ANLEITUNG LERNUMGEBUNG


Auf dieser Seite der Lernplattform soll Ihnen eine Erklärung darüber gegeben werden, wie sie die Lernumgebung mit dem Hilfsmittel am einfachsten und effizientesten nutzen können.

Lesen

Um den Inhalt einer Seite lesen zu können, können Sie die Pfeiltasten und die gängigen Tastenbefehle von Ihrem Hilfsmittel nutzen. Folgend eine kleine Auflistung:

Wortweise lesen: Control + Pfeil rechts / links ODER Insert + Pfeil rechts / links

Absatzweise lesen: Control + Pfeil runter / rauf

Satzweise lesen: Alt + + / -

Lesen ab Cursorposition: Insert + Pfeil runter



Überschriften

Die meisten Seiten sind mit Überschriften versehen. Um diese direkt anspringen zu können, drücken sie einfach den Buchstaben h. Jedes Mal, wenn Sie h drücken, springen Sie zur nächsten Überschrift. Sind Sie bei der letzten angekommen, fängt es wieder zuoberst an.


Links und Tabs

Gewisse Inhalte der Seite sind mit Links versehen. Um direkt auf einen Link auf der Seite zu kommen, kann die Linkliste mit Insert + F7 benutzt werden.

Wird ein Link betätigt, öffnet sich dieser in einem neuen Tab.

Um den Tab zu schliessen, nutzen Sie die Tastenkombination Control + W.

Für das hin und her wechseln zwischen den Tabs können Sie Control + Tab ODER Control + Page Up / Page Down.


Download von Dokumenten

Auf gewissen Seiten finden Sie zusätzliches Übungsmaterial. Der Download dieser Dateien funktioniert ähnlich wie bei den Links. Wenn Sie darauf Enter drücken, dann wird das Dokument direkt heruntergeladen. Sie finden es auf Ihrem Notebook unter Downloads. Verschieben Sie diese Datei an einen Ort, an dem Sie es wieder finden.

Wenn Sie das Dokument öffnen, kann es sein, dass sie in einer geschützten Ansicht sind. Um diese zu deaktivieren, drücken Sie Enter, dann F6 und einmal Tab. Sie hören: Bearbeiten aktivieren Schalter. Drücken Sie Enter. Jetzt sollten Sie das Dokument bearbeiten können.

Formularfelder

Auf einigen Seiten gibt es Übungen, die direkt in der Lernumgebung gelöst werden können. Folgend die verschiedenen Formen und wie sie behandelt werden sollen.


Schalter

Um einen Schalter zu aktivieren, drücken Sie Enter.

Folgend ein Beispiel: Steuern Sie den Schalter an und drücken Sie Enter, um ihn zu aktivieren.



Auswahl Schalter

Bei einem Auswahl Schalter handelt es sich um ein Kästchen, welches aktiviert werden muss. Um ein Kästchen zu aktivieren, drücken Sie die Leertaste. Es ist jeweils nur eine Antwort richtig. Haben Sie aus Versehen einen falschen Auswahl Schalter mit der Leertaste aktiviert, dann navigieren Sie einfach zur richtigen Antwort und drücken Sie dort die Leertaste.

Eingabefeld

Bei einem Eingabefeld handelt es sich um ein Textfeld, in das ein Wort oder ein Text geschrieben werden kann. Wenn Sie mit Ihrem Cursor auf einem Eingabefeld stehen, dann mssen Sie zuerst die Leertaste drücken, um hineinschreiben zu können. Haben Sie Ihren Text zu Ende geschrieben, dann verlassen Sie das Eingabefeld mit Escape.

Ausklappliste

Bei einer Ausklappliste sind eine bestimmte Anzahl an Optionen vorgegeben. Eine der Optionen ist die richtige Antwort. Wenn Ihr Cursor auf der Ausklappliste steht, kann diese mit alt + Pfeil runter ausgeklappt werden. Mit Pfeil rauf / Pfeil runter können Sie die Optionen durchgehen. Innerhalb der Ausklappliste werden die Optionen immer auf Deutsch vorgelesen, auch wenn Englische Wörter dort stehen. Wenn Sie Ihre Antwort gefunden haben, drücken Sie Escape, um die Ausklappliste wieder zu schliessen.
